# Trabalho Grupo 4 - React + Vite

## Diário de Avistamentos ET

Projeto desenvolvido em grupo para a disciplina de Desenvolvimento Web com React.

A aplicação consome a API do Serratec e possui autenticação, navegação entre páginas e gerenciamento de dados relacionados a avistamentos extraterrestres.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- Axios
- React Router DOM
- CSS
- Bootstrap
